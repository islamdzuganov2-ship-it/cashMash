# 📖 20 · Глоссарий и нотация

## Крипто-рынок

| Термин | Определение |
|--------|-------------|
| **Спот** | Покупка реальной монеты за USDT. Нельзя шортить, нет плеча и ликвидации |
| **Перпетуал (perp)** | Бессрочный фьючерс. Можно шортить, есть плечо, есть фандинг и ликвидация. На Bybit категория `linear` = USDT-маржинальные |
| **USDT-margined (linear)** | Залог и расчёт в USDT. Проще в учёте, чем inverse (залог в монете) |
| **Фандинг** | Платёж между лонгами и шортами, каждые 8 часов. Начисляется **по факту наличия позиции в момент расчёта**, не пропорционально времени |
| **Ликвидация** | Принудительное закрытие биржей при нехватке маржи. Исполняется по цене банкротства, с дополнительной комиссией |
| **Изолированная маржа** | Под риском только маржа этой позиции |
| **Кросс-маржа** | Под риском весь баланс. В проекте запрещена |
| **Реальное плечо** | `номинал позиции / equity`. Не путать с настройкой плеча на бирже, которая влияет только на размер блокируемой маржи |
| **Maker** | Лимитная заявка, добавляющая ликвидность в стакан. Комиссия ниже |
| **Taker** | Заявка, забирающая ликвидность. Комиссия выше |
| **PostOnly** | Флаг: если заявка при постановке пересечёт стакан, она **отклоняется**, а не исполняется тейкером. Гарантия maker-комиссии |
| **reduceOnly** | Флаг: ордер может только уменьшать позицию. Защита от случайного переворота |
| **IOC / FOK / GTC** | Время жизни заявки: исполнить сколько можно и отменить остаток / всё или ничего / до отмены |
| **One-way / Hedge mode** | Одна позиция на символ / две встречные. В проекте — one-way |
| **Стакан (order book, L2)** | Уровни цен с объёмами по обе стороны |
| **Лента (tape, publicTrade)** | Поток состоявшихся сделок с указанием агрессора |
| **Book imbalance** | Дисбаланс объёмов в стакане: `(bid_vol − ask_vol) / total` |
| **Tape aggression** | Перевес агрессивных покупок над продажами за окно |
| **minOrderQty / qtyStep** | Минимальное количество и шаг. Количество обязано быть кратно шагу |
| **minNotionalValue** | Минимальная стоимость ордера. На перпах Bybit — **5 USDT**. Определяет, доступен ли инструмент при малом депозите |
| **tickSize** | Шаг цены |
| **orderLinkId** | Клиентский идентификатор ордера. Основа идемпотентности |
| **retCode** | Код результата в теле ответа Bybit. HTTP 200 при этом не означает успех |

## Издержки и метрики

| Термин | Определение |
|--------|-------------|
| **bps (базисный пункт)** | 0.01% = 1/10 000. Единица измерения всего в этом проекте |
| **C_total** | Полная стоимость круга: комиссия вход + комиссия выход + спред + проскальзывание + доля фандинга |
| **Maker ratio** | Доля исполнений по maker-комиссии. Главная метрика реализации экономики |
| **Post-only reject rate** | Доля post-only заявок, отклонённых из-за пересечения стакана. Нормальное явление, не ошибка |
| **Fill ratio** | Доля выставленных заявок, дошедших до исполнения |
| **R** | Единица риска. 1R = убыток при срабатывании исходного стопа |
| **RR** | Отношение цели к стопу |
| **Expectancy** | Матожидание сделки: `p·avg_win − (1−p)·avg_loss` |
| **Edge** | Статистическое преимущество; положительная expectancy **после** издержек |
| **MFE / MAE** | Максимальная благоприятная / неблагоприятная экскурсия позиции |
| **Order-to-trade ratio** | Ордеров на одно исполнение. Высокое значение жжёт лимиты и привлекает внимание риск-систем |
| **RTT** | Round-trip time: от отправки запроса до ответа |
| **WS lag** | Разница между временем события на бирже и моментом его получения |

## Статистика и валидация

| Термин | Определение |
|--------|-------------|
| **IS / OOS** | In-Sample (подбирали) / Out-of-Sample (подбор не видел) |
| **WFA** | Walk-Forward Analysis: «оптимизировали на окне → проверили на следующем», последовательно |
| **WFE** | Walk-Forward Efficiency = доходность OOS / доходность IS |
| **CPCV** | Combinatorial Purged Cross-Validation: кросс-валидация по блокам времени; даёт **распределение** OOS-результатов вместо одной траектории |
| **Purge** | Удаление обучающих примеров, пересекающихся по времени с тестовыми |
| **Embargo** | Буфер после тестового блока против протечки автокорреляции |
| **PBO** | Probability of Backtest Overfitting: вероятность, что лучшая на IS конфигурация окажется ниже медианы на OOS |
| **DSR** | Deflated Sharpe Ratio: Sharpe с поправкой на число испытаний, асимметрию и эксцесс |
| **t-stat** | `mean / (std / √N)` — во сколько стандартных ошибок среднее отличается от нуля |
| **Монте-Карло (перестановка)** | Случайная перестановка порядка сделок для оценки распределения просадки |
| **Bootstrap** | Ресэмплинг сделок с возвращением |
| **Плато параметров** | Область, где результат мало меняется при сдвиге параметров. Противоположность — пик, признак подгонки |
| **Kelly fraction** | Теоретически оптимальная доля капитала на ставку. Используется как верхняя граница, не как формула |

## Технические сокращения

| Сокращение | Значение |
|-----------|----------|
| **WS** | WebSocket. Push-поток данных вместо опроса |
| **REST** | Запрос-ответ по HTTP |
| **testnet** | Тестовый контур биржи с виртуальными деньгами |
| **Decimal** | Тип точной десятичной арифметики. Вся работа с деньгами — только им, никогда float |
| **structured concurrency** | Модель asyncio, где задачи имеют владельца и их исключения не теряются |
| **fail-closed** | При неопределённости — отказ от действия. Базовый принцип проекта |
| **идемпотентность** | Повторная отправка того же запроса не создаёт второй эффект |
| **реконсиляция** | Сверка локального состояния с биржей; при конфликте права биржа |
