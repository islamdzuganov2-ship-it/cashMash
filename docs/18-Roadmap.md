# 🗺 18 · Дорожная карта

Оценки — в человеко-днях разработчика, знакомого с Python и биржевыми API. Календарные сроки больше из-за фаз наблюдения, которые нельзя ускорить: 4 недели testnet — это 4 недели, сколько бы людей на них ни поставили.

## Фаза 0 · Подготовка и издержки — 3–5 дн · 🟢 почти закрыта

| Задача | Дн | Статус |
|--------|-----|--------|
| Выбор платформы, рынка, инструмента | 0.5 | ✅ Bybit / linear / XRPUSDT |
| Замер спецификаций и издержек (`bybit_instruments.py`) | 0.5 | ✅ 7.5 bps, minNotional 5 USDT |
| Решение по источнику данных (Q8) | 0.5 | ✅ архивы Bybit + собственный сбор |
| **Сборщик данных** (`collect_bybit.py`) | 1 | ✅ написан и проверен на живом потоке |
| Канал алертов (Q10) | 0.5 | 🟡 агент готов, ждём токен бота |
| Проверка комиссионного уровня аккаунта | 0.2 | ⚪ |
| Фиксированная точка выхода в сеть (Q9, см. 15.2) | 0.5 | ⚪ решает проблему привязки ключа к IP |
| Репозиторий, CI (mypy/ruff/pytest), Docker-скелет | 1.5 | ⚪ |

**Гейт 0.** Главное, что должно быть сделано именно сейчас, — **запущен сбор данных**. Всё остальное можно наверстать; упущенное время сбора наверстать нельзя.

> ⏱ **Сбор запущен = часы пошли.** К началу фазы 2 (через ~1.5–2 месяца) накопится история стакана, которую иначе пришлось бы покупать. См. [[23-Data-Pipeline]].

## Фаза 7 · Развитие

| Направление | Условие запуска |
|------------|----------------|
| Переход на SOLUSDT | депозит ≥ $50, подтверждённый эдж |
| Второй символ / портфель | 3 месяца стабильного live на первом |

## Что уже запущено параллельно

**Сбор истории стакана и ленты** — `research/collect_bybit.py`, готов и проверен. Запускается одной командой, пишет ~65 МБ в сутки, переживает жёсткое завершение процесса.

```bash
.venv/Scripts/python research/collect_bybit.py --symbol XRPUSDT
```

Это самая ценная задача проекта по отношению пользы к затратам: полдня работы сегодня даёт к фазе 2 данные, которые иначе покупаются. Детали — [[23-Data-Pipeline]].

## Критический путь и риски графика

| Риск | Вероятность | Митигация |
|------|------------|----------|
| Гейт 3: эдж не подтверждается на OOS | **высокая** | Нормальный исход. Заложить итерацию на смену класса сигнала (+3–4 недели) |
| Нет качественных данных стакана | **высокая** | Начать собственный сбор в фазе 0; для первой итерации хватит тиковых сделок |
| Переоценка maker-исполнения в бэктесте | высокая | Консервативная модель очереди + стресс «50% неисполнения» |
| Издержки съедают эдж | средняя | Гейт издержек на этапе проектирования, а не после |
| Самоблокировка по лимитам | средняя | Разбирается в фазе 1, проверяется нагрузочным тестом |
| Bybit меняет спецификации или комиссии | низкая | Ежедневная сверка, алерт при расхождении |
